# SEO Notes — NoteSnap Marketing Site

Status: shipped 2026-08-17 (branch `feat/seo-indexing`, PR #___).

## What shipped
- **noindex removed (root cause: platform, not code).** `site-notesnap.vercel.app`
  was NOT a registered domain of the Vercel project, so Vercel served every
  `*.vercel.app` host with `x-robots-tag: noindex` — even `--prod` deployments.
  Fixed by registering `site-notesnap.vercel.app` as a project domain
  (POST /v10/projects/.../domains, verified). Verified live: header gone from `/`
  and `/library`. `go-live.sh` now registers the production domain on every
  deploy so this cannot silently return (idempotent; 409 = already exists).
- **robots.txt** (`public/robots.txt`): allow all + `Sitemap:` line.
- **sitemap.xml** (`src/services/sitemap-handler.ts`, wired into serve.ts +
  vercel-entry.ts before SSR): static routes (/, /library, /privacy, /terms,
  /data-deletion, /subscription/cancel, /subscription/success) + one URL per
  public-domain piece (`/library/:id`, read live from the DB each request; DB
  failure degrades to static-only, never a 500).
- **Per-page titles + meta descriptions** (all render in server HTML — SSR head
  per route; deepest route wins in TanStack's head merge):
  - `/` — "NoteSnap — Identify Music & Find Sheet Music Instantly (Shazam for Sheet Music)"
  - `/library` — "Sheet Music Library — 500+ Free Public-Domain Classical Scores | NoteSnap"
  - `/library/:pieceId` — dynamic "«Title» Sheet Music — Free PDF | «Composer» | NoteSnap"
    (from the route loader's piece data; sensible default when piece missing)
  - `/privacy`, `/terms`, `/data-deletion`, `/subscription/*` — unique titles + descriptions
- **JSON-LD**: `MusicComposition` on piece pages (name, composer, url,
  isAccessibleForFree for PD, difficulty as additionalProperty); `WebSite` +
  `Organization` + SearchAction on the homepage.
- **Canonical** (`rel=canonical`, absolute) on every page — intentionally only
  in leaf routes (TanStack emits all route links without dedup, so a root
  canonical would double up). No query-string pagination exists yet; canonicals
  point at the clean path (future pagination should emit per-page canonicals).
- **OG/social**: `og:title/description/image/url`, `twitter:card` on all pages;
  `public/og-image.png` (1200×630, amber/stone brand card, ~24 KB, generated by
  `scripts/generate-og-image.py` — Pillow, rerun after design edits). Piece
  pages use their album art when an absolute URL exists, else the default.

Expected: homepage title contains "Identify Music"; piece title contains
"Sheet Music — Free PDF"; sitemap contains `/library/` piece URLs.

## Google Search Console steps (OWNER — from their Google account)
1. Go to https://search.google.com/search-console → "Add property" →
   **Domain** (or URL prefix). Recommended: **Domain**, enter `site-notesnap.vercel.app`.
2. Verify ownership. Easiest: **HTML tag** method — copy the
   `<meta name="google-site-verification" content="...">` tag, and either
   (a) add it to `src/routes/__root.tsx` root head meta (team can deploy it), or
   (b) create `public/<hash>.html` (a static file — team can add it).
   Alternative: **DNS TXT** record at the domain registrar if the owner has DNS access.
   (Vercel domain verification for `notesnap.app` is also pending — adding the
   `_vercel.notesnap.app` TXT record `vc-domain-verify=notesnap.app,3b94a9a8965dc11f531d`
   would enable the custom domain later; not required for Search Console.)
3. Once verified: **Sitemaps** → submit `https://site-notesnap.vercel.app/sitemap.xml`.
4. **URL Inspection** → enter `https://site-notesnap.vercel.app/` → "Request indexing".
   Also request indexing for `/library` after submission.
5. Expect: Google must crawl + render before results appear (days to weeks).
   `x-robots-tag: noindex` is gone, so nothing blocks it.
